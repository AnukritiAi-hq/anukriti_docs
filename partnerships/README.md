# Partnerships — Scientific & Data Outreach

> Tracking record for outreach to scientific authorities, data
> custodians, and nomenclature stewards in the pharmacogenomics
> ecosystem.
>
> **Distinct from `investor-outbound/`** (capital outreach) and
> `founder-research/` (prospective hire research). This directory
> captures correspondence with the people who shape the *evidence
> base* Anukriti consumes.

---

## Why this directory exists

Anukriti's deterministic engine is built against external
nomenclature and guideline registries — PharmVar (allele
definitions), CPIC (phenotype-to-recommendation mapping),
PharmGKB, ClinVar, gnomAD/1000G, and a small set of
population-specific cohort projects (LASI-DAD, GenomeIndia,
H3Africa, All of Us). Staying aligned with these registries is
not optional — when CPIC or PharmVar publishes an update,
Anukriti's pinned tables need to be audited and re-pinned.

The contact list, threads, and follow-ups here are the
relationship layer underneath that audit pipeline. Every record
captures:

- Who was contacted, when, and via what channel
- The specific scientific or partnership question
- The response (verbatim where possible)
- Action items derived from the response
- Follow-up status

Cross-references the formal Phase C contact list in
`../IDEA_REFINEMENT_AND_PHASING_2026-05-14.md`.

## Naming convention

`NN-LastName-Affiliation-topic-slug.md`

  - `NN` is the thread number (zero-padded), assigned in order
    of first contact.
  - One file per thread (not per email). Append new exchanges
    in chronological order at the bottom of the same file.
